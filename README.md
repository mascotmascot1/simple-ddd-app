## Общая информация об api

Документация составлена на основе предоставленного кода обработчиков и структур данных. Базовый путь для всех запросов этого домена: `/api/v1/orders`.

Все запросы и ответы используют формат данных `application/json`. На сервере также установлено ограничение на максимальный размер тела входящего запроса для защиты от переполнения памяти. Идентификаторы (id) во всех эндпоинтах строго валидируются на соответствие формату uuid.

---

## Формат ошибок

Если запрос не прошел валидацию или произошла системная ошибка, сервер вернет соответствующий http-статус (400, 404 или 500) и тело ответа в едином формате:

```json
{
  "error": "текст ошибки"
}

```

---

## Создание нового заказа

* **Метод и путь:** `post /api/v1/orders/`
* **Описание:** Инициализирует новый заказ для указанного клиента.

**Тело запроса:**

| Поле          | Тип данных | Описание и валидация                                           |
| :------------ | :--------- | :------------------------------------------------------------- |
| `customer_id` | строка     | Идентификатор клиента. Обязательно должен быть в формате uuid. |

**Пример успешного ответа (статус 201 created):**

```json
{
  "order_id": "123e4567-e89b-12d3-a456-426614174000"
}

```

---

## Получение информации о заказе

* **Метод и путь:** `get /api/v1/orders/{orderID}`
* **Описание:** Возвращает полную агрегированную информацию о заказе, включая итоговую стоимость и список всех добавленных позиций.
* **Параметры пути:** `orderID` (строка, формат uuid).

**Пример успешного ответа (статус 200 ok):**

```json
{
  "order_id": "123e4567-e89b-12d3-a456-426614174000",
  "customer_id": "987fcdeb-51a2-43d7-9012-345678901234",
  "currency": "rub",
  "total_amount": 1500,
  "items": [
    {
      "product_id": "a1b2c3d4-e5f6-7a8b-9c0d-1e2f3a4b5c6d",
      "amount": 500,
      "currency": "rub",
      "quantity": 3
    }
  ]
}

```

## Добавление товара в заказ

* **Метод и путь:** `post /api/v1/orders/{orderID}/items`
* **Описание:** Добавляет новую позицию (товар) в существующий заказ.
* **Параметры пути:** `orderID` (строка, формат uuid).

**Тело запроса:**

| Поле         | Тип данных  | Описание и валидация                                           |
| :----------- | :---------- | :------------------------------------------------------------- |
| `product_id` | строка      | Идентификатор товара. Строго формат uuid.                      |
| `amount`     | целое число | Цена за единицу товара. Не может быть меньше нуля.             |
| `currency`   | строка      | Валюта товара. Не может быть пустой строкой.                   |
| `quantity`   | целое число | Количество товара. Должно быть строго больше нуля.             |

**Успешный ответ (статус 200 ok):** Пустое тело ответа.

---

## Удаление заказа

* **Метод и путь:** `delete /api/v1/orders/{orderID}`
* **Описание:** Удаляет существующий заказ по его идентификатору.
* **Параметры пути:** `orderID` (строка, формат uuid).

**Успешный ответ (статус 204 no content):**
Пустое тело ответа. Игнорирует возврат данных, так как ресурс успешно удален.
